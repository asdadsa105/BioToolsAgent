# BWA工具Skill

## 1. 工具基本信息

**工具名称**: BWA (Burrows-Wheeler Aligner)
**工具版本**: 0.7.17
**工具分类**: 序列比对类
**工具描述**: 高效的短读长序列比对工具，支持将FASTQ格式的测序数据比对到参考基因组，适用于全基因组、外显子组和目标区域测序数据的比对
**工具来源**: https://github.com/lh3/bwa
**Docker镜像**: biocontainers/bwa:v0.7.17_cv1

## 2. 输入参数规范

### 2.1 必需参数

| 参数名称 | 短参数 | 长参数 | 参数类型 | 参数说明 | 默认值 | 是否支持通配符 | 取值 |
|---------|--------|--------|---------|---------|--------|----------------|------|
| 参考基因组索引 | - | - | 文件路径 | 参考基因组的BWA索引文件前缀 | 无 | 不支持 | 必填 |
| 输入FASTQ文件 | - | - | 文件路径 | 输入的FASTQ文件（单端或双端） | 无 | 支持 | 必填 |

### 2.2 可选参数

| 参数名称 | 短参数 | 长参数 | 参数类型 | 参数说明 | 默认值 | 推荐值范围 | 取值 |
|---------|--------|--------|---------|---------|--------|------------|------|
| 比对算法 | -a | - | 字符串 | 比对算法：mem/bwasw/backtrack/ssw | mem | mem | 推荐 |
| 线程数 | -t | - | 整数 | 线程数 | 1 | 1-32 | 推荐 |
| 输出文件 | -o | - | 文件路径 | 输出的SAM文件路径 | stdout | - | 推荐 |
| 质量值编码 | -L | - | 整数 | 质量值编码（33或64） | 自动检测 | 33/64 | 可选 |
| 错配惩罚 | -B | - | 整数 | 错配惩罚值 | 4 | 1-10 | 可选 |
| 缺口打开惩罚 | -O | - | 整数 | 缺口打开惩罚值 | 6 | 1-20 | 可选 |
| 缺口延伸惩罚 | -E | - | 整数 | 缺口延伸惩罚值 | 1 | 1-10 | 可选 |
| 最小种子长度 | -k | - | 整数 | 最小种子长度 | 19 | 10-30 | 可选 |
| 最大种子间隔 | -w | - | 整数 | 最大种子间隔 | 100 | 50-200 | 可选 |
| 种子数 | -d | - | 整数 | 每个查询序列的最大种子数 | 1000000 | - | 可选 |
| 匹配得分 | -A | - | 整数 | 匹配得分 | 1 | 1-5 | 可选 |
| 不匹配得分 | -B | - | 整数 | 不匹配得分（负数） | -4 | -10--1 | 可选 |
| 读取组信息 | -R | - | 字符串 | 读取组信息，格式为"@RG\tID:id\tSM:sample\tLB:lib\tPL:platform" | "" | - | 推荐 |
| 忽略质量值 | -C | - | 布尔值 | 忽略质量值 | false | false | 可选 |
| 软剪辑 | -S | - | 布尔值 | 软剪辑而不是硬剪辑 | false | false | 可选 |

- **必需前置工具**: 无（但需要参考基因组索引）

### 6.2 后置工具

| 工具名称 | 工具分类 | 适用场景 |
|---------|---------|----------|
| samtools | 数据处理类 | SAM/BAM文件处理和排序 |

- **互斥工具**: hisat2, STAR, bowtie2（功能重叠，选择一种即可）
- **替代工具**: minimap2（长读长数据）

## 7. 使用场景模板

### 7.1 场景1: 全基因组重测序比对

**适用场景**: 人类全基因组重测序数据的比对
**输入数据**: 双端FASTQ文件，人类参考基因组索引
**推荐参数**:
```bash
bwa mem -t 8 -R "@RG\tID:sample1\tSM:sample1\tLB:lib1\tPL:ILLUMINA" \
  human_g1k_v37 \  # 参考基因组索引前缀
  sample1_1.fq.gz sample1_2.fq.gz \
  > sample1.sam
```
**预期输出**:
- 比对后的SAM文件，包含详细的比对信息和读取组信息
- 比对率通常在95%以上

### 7.2 场景2: 外显子组测序比对

**适用场景**: 外显子组测序数据的比对
**输入数据**: 双端FASTQ文件，人类参考基因组索引
**推荐参数**:
```bash
bwa mem -t 4 -R "@RG\tID:exome1\tSM:exome1\tLB:lib1\tPL:ILLUMINA" \
  human_g1k_v37 \
  exome1_1.fq.gz exome1_2.fq.gz \
  > exome1.sam
```
**预期输出**:
- 比对后的SAM文件，包含外显子区域的比对信息
- 比对率通常在90%以上

### 7.3 场景3: 目标区域测序比对

**适用场景**: 目标区域（如基因Panel）测序数据的比对
**输入数据**: 双端FASTQ文件，人类参考基因组索引
**推荐参数**:
```bash
bwa mem -t 4 -R "@RG\tID:panel1\tSM:panel1\tLB:lib1\tPL:ILLUMINA" \
  human_g1k_v37 \
  panel1_1.fq.gz panel1_2.fq.gz \
  > panel1.sam
```
**预期输出**:
- 比对后的SAM文件，包含目标区域的比对信息
- 比对率通常在85%以上

## 8. 质量控制指标

### 8.1 输入数据要求

| 指标 | 要求 | 说明 |
|------|------|------|
| 序列质量 | Q20 > 80% | 输入数据质量应在可接受范围内 |
| 序列长度 | ≥ 36bp | 过短的序列可能导致比对率低 |
| 参考基因组 | 已索引 | 参考基因组必须预先构建BWA索引 |
| 数据量 | ≥ 1M reads | 数据量过小可能导致统计结果不可靠 |

### 8.2 输出质量检查

| 检查项目 | 检查方法 | 合格标准 |
|---------|---------|----------|
| 比对率 | samtools flagstat | > 80% |
| 唯一比对率 | samtools view -F 4 | > 70% |
| 配对率 | samtools flagstat | > 90% |
| 平均比对质量 | samtools stats | > 30 |
| 覆盖度 | samtools depth | 符合预期 |

### 8.3 常见错误处理

| 错误类型 | 错误信息 | 解决方案 |
|---------|---------|----------|
| 索引文件不存在 | `[E::bwa_idx_load_from_disk] fail to locate the index files` | 检查索引文件路径和完整性 |
| 输入文件不存在 | `[E::faidx_read_seq] fail to open file` | 检查输入文件路径是否正确 |
| 内存不足 | `[mem_sam_pe] fail to allocate` | 增加内存配置或减少线程数 |
| 线程数过多 | `[bwa] Cannot allocate memory for thread pool` | 减少线程数，不超过系统可用CPU |
| 质量值编码错误 | `[bwa_idx_read] mutiple different quality encodings` | 指定正确的质量值编码 |

## 9. 工具执行示例

### 9.1 基本用法

**单端数据比对**:
```bash
bwa mem -t 4 reference_index input.fq.gz > output.sam
```

**双端数据比对**:
```bash
bwa mem -t 8 reference_index input_1.fq.gz input_2.fq.gz > output.sam
```

### 9.2 高级用法

**指定读取组信息**:
```bash
bwa mem -t 4 -R "@RG\tID:sample1\tSM:sample1\tLB:lib1\tPL:ILLUMINA" \
  reference_index input_1.fq.gz input_2.fq.gz > output.sam
```

**调整比对参数**:
```bash
bwa mem -t 8 -k 15 -B 3 -O 11 -E 4 \
  reference_index input_1.fq.gz input_2.fq.gz > output.sam
```

**直接输出BAM格式**:
```bash
bwa mem -t 8 reference_index input_1.fq.gz input_2.fq.gz | \
  samtools view -bS - > output.bam
```

## 10. 工具优势与局限性

### 10.1 优势
- **速度快**: 高度优化的比对算法，支持多线程
- **准确性高**: 特别是mem算法对长读长数据比对准确
- **灵活性强**: 支持多种比对算法，适应不同数据类型
- **广泛应用**: 是人类基因组研究的标准比对工具
- **稳定可靠**: 长期维护，版本稳定

### 10.2 局限性
- **内存消耗大**: 特别是对大基因组，内存需求较高
- **索引构建时间长**: 首次构建参考基因组索引需要较长时间
- **对长读长支持有限**: 虽然有bwasw算法，但长读长数据推荐使用minimap2
- **参数调优复杂**: 不同数据类型需要不同的参数配置
- **输出文件大**: SAM文件通常比输入数据大很多
